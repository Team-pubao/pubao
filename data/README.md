# 푸바오 — 시군구 입지요인 데이터셋 (전처리 완료)

## 이 데이터의 위치
- **분석 본체(회귀)**: 기존에 보유한 **시도(N=17) 26그룹** 데이터를 사용 권장
  - 이유: 종속변수 Y(사업체수)가 **시군구 × 산업중분류로는 공개되지 않음**(공개 KOSIS는 시군구=대분류만 → 제조업이 한 덩어리라 반도체·조선·석유화학 구분 불가). 시군구 26그룹은 MDIS 신청이 필요.
- **이 데이터셋(시군구 4요인)**: 위 한계 때문에 회귀 본체가 아니라 **지도·맥락·확장 시각화용**으로 정리한 것. 추후 MDIS로 Y(시군구)를 확보하면 `시도+시군구` 키로 그대로 병합 가능.

## 메인 파일 컬럼 (시군구_4요인_통합.csv)
- `시도`, `시군구` — 키
- `항만거리_km` — 시군구 중심에서 **가장 가까운 무역항까지 거리**(H1)
- `최근접무역항` — 그 무역항 이름
- `IC수`, `IC밀도_per1000km2` — 고속도로 IC 수 / 1000km²당 밀도(H2)
- `산업용전력_2024_kWh`, `산업용전력_2023_kWh` — 산업용 전력 사용량(H3)
- `평균급여_만원` — 거주지 기준 평균 근로소득(H4 프록시)
- `면적_km2`, `lat`, `lng` — 면적·중심좌표

## 전처리 방법 (출처·계산)
- **전력(H3)**: KEPCO 시군구별 전력판매량 → `계약종별=산업용`의 12개월 합. 메인은 2024년(202412 파일). 전국 2024 ≈ 286 TWh로 검증.
- **임금(H4)**: 국세청 시·군·구별 근로소득 연말정산(주소지, 2023). `평균급여 = 급여총계 금액(백만원) ÷ 인원 × 100(만원)`. 전국 평균 ≈ 4,424만원.
- **IC(H2)**: 한국도로공사 IC 좌표(508개, JC·TG 제외) → 시군구 경계와 **점-폴리곤 결합**으로 시군구별 IC수 산출. 밀도 = IC수 ÷ 면적 × 1000.
- **항만(H1)**: 해수부 항만정보의 무역항 31개 중 30개 좌표(항구역 도분초 파싱 + 부산항 보완) → 각 시군구 중심에서 **최근접 무역항까지 haversine 거리**.
- **경계/면적**: southkorea-maps의 2018 시군구 GeoJSON(EPSG:5179 투영으로 면적 km² 계산).

## 주의사항
- **단위 통일**: 통합시(수원·성남·고양·용인·안산·부천·청주·천안·전주·포항·창원 등)는 전력·임금이 '시' 단위라 **모두 '시' 단위로 집계**. GeoJSON은 '구' 단위지만 `시군구_표준` 속성으로 '시' 단위 그룹핑(dissolve) 가능.
- **미매칭(극소수)**: `군위군`(2023년 대구 편입으로 경계는 경북·데이터는 대구), 무역항 중 `완도항`(좌표 미확보) 1곳. → 분석엔 거의 영향 없음.
- **인과 아님**: 모든 결과는 상관·패턴으로 해석.
